# Agent architecture

Agents are bounded roles, not autonomous authorities. Every output identifies its authoring role, inputs, claim/source IDs, uncertainty, and requested review. Agents cannot promote their own opportunity, convert hypotheses to facts, or conceal conflicts.

## Workflow

Director issues a question and acceptance criteria → specialists collect/analyze independently → structured records validate → Circular agent links systems → Modeler creates explicit scenarios → Skeptic tries to disprove → Director synthesizes and a human owner decides.

For independent discovery, run multiple agents in blinded workspaces with the same geography/time budget and no access to one another's candidates. Reveal outputs only after submission; deduplicate at synthesis; calculate and record the non-founder-derived share (minimum 50%). Founder prompts are tagged and withheld where needed.

Each role contract in `roles.md` defines mandate, outputs, prohibited behavior, and handoffs. Least-privilege access, run logs, deterministic IDs, source snapshots where lawful, and human approval are required for consequential changes.
