# Local Fabrication & Machine Intelligence

AII treats machinery as functions and components, not catalogue products.

## Decomposition

Each machine records function, throughput basis, assemblies, components, materials/specifications/tolerances, criticality, food/safety constraints, wear parts, maintenance skills and downtime risks.

Localization is explicit:
- fabricate locally now;
- source locally now;
- assemble locally using imported components;
- local after training/tooling;
- import required;
- unknown.

A component count is never represented as local-content value percentage. Cost/value must be separately evidenced.

## Pathways

For each required machine the research room investigates five paths: new import, used equipment, modify existing equipment, local fabrication, and shared processing/service. It gathers the evidence appropriate to each instead of assuming one path is superior.

## Recurrence

Recurring motors, bearings, screens, shafts, frames, controls, sensors, food-contact assemblies or fabrication processes across missions create hypotheses for pooled procurement, repair/remanufacture, standardization, local component production or a dedicated machinery company.

## Maagal loop

Components marked local-after-training create competency/tooling hypotheses for Maagal Cayor. A training hypothesis requires defined skill, tooling, instructor/knowledge source, prototype and acceptance test. It is not considered a capability merely because a course exists.

## Validation

A fabricated/modified prototype is not validated because it operates. Acceptance tests can cover throughput, yield/loss, energy/water, product quality, sanitation, safety, noise/vibration, downtime and changeover. Failed prototypes remain learning records and are revised/retested.

## Design-for-Africa research questions

Machine research should explicitly test maintainability, dust/heat/humidity, voltage/power quality, operator skill, cleaning, locally obtainable wear parts, modularity, manual fallback where appropriate, low-bandwidth controls, repair documentation and safe simplification. These are engineering constraints to investigate, not excuses for lower quality.
