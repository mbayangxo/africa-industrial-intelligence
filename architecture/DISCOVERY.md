# Discovery architecture

Every candidate declares one or more governed modes:

| Mode | Core question | Minimum evidence before research promotion |
|---|---|---|
| Import leakage | Could an imported product competitively be produced/processed in Africa? | Harmonized product, demand persistence, landed/local cost drivers, capability and constraints |
| Raw-value leakage | Is further local processing economically sensible? | Material flow, product markets, recovery, utilities, standards and logistics |
| Infrastructure gap | Which missing service blocks multiple firms? | User/service-level evidence, reliability gap, willingness to pay, shared-use case |
| Essential business | Which recurring mission-critical spend is underserved? | Recurrence, mandatory nature, fragmentation/density, service economics |
| Empty shelf | Where are African-owned brands weak/absent/uncompetitive? | Audited assortment, ownership, consumer/retailer evidence, product/pack benchmark |
| Waste → value | Who can safely and profitably use an output? | Composition/consistency, volume/location, treatment, buyer specification, regulation |
| Technology reset | How would the industry be designed today? | Baseline bottleneck, technical readiness, integration/skills, whole-life advantage |
| Africa advantage | What capability competes without exploitative wages? | Quality/productivity/logistics basis, wage safeguards, addressable demand |
| Missing middle | What lies between fragmented informal and expensive large providers? | Segment gap, service level, price/value, aggregation economics |
| Picks and shovels | What essential input/service serves a growing sector? | Customer growth, criticality, repeat spend, switching/substitution risk |
| Independent | What was not suggested by the founder? | Blind provenance, distinct need, mode evidence; cycle-level ≥50% non-derived |

## Candidate funnel

Signals become hypotheses, not opportunities. Capture candidates in `opportunity.schema.json`; link atomic claims; score only after comparable evidence. Promote via research coverage, engineering/economics, standards, circular review, and mandatory red team. Ranking must expose weights and missing-data penalties.

## Graph prompts

On every `produces` edge ask who can use/buy it; on every imported input ask which African node can supply it; on every infrastructure node ask who can share it. Find directed cycles over validated and candidate edges separately, retain edge classifications, and never interpret a graph loop as commercial viability without volume, quality, timing, logistics, safety, regulation, and economics.
