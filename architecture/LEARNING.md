# Institutional Learning Layer

AII must become more useful after every mission. It persists reusable capabilities, recurring constraints, rejected hypotheses, machine/component knowledge, supplier knowledge, field findings, cross-mission relationships and later real operating outcomes.

## Critical rule

**Retrieval is not promotion.** A finding from rice may inform an oilseed hypothesis; it does not automatically become an oilseed fact. A Senegal finding may seed a question elsewhere; it does not become evidence for that geography.

Every learning carries origin mission, geography, date, claim/source lineage and a reuse rule: context-only, must-refresh, portable-technical, or field-reverify.

Rejected ideas remain searchable with the reason they failed so later agents do not rediscover and re-sell the same thesis without new evidence.

## Capability graph

Long-term value comes from connecting capabilities: cleaning → grading → drying → storage → testing → pressing → packaging → cold chain → logistics → merchant distribution → maintenance/fabrication. If several missions repeatedly require the same missing capability, Infrastructure and Independent Discovery should receive that pattern as a new opportunity hypothesis.

## Reality feedback

Once a Foundry company operates, actual throughput, yield, downtime, repairs, labor productivity, rejects, inventory days, merchant reorder, customer repeat, acquisition cost and realized co-product value become operating-outcome learnings. Research estimates can then be calibrated against African operating reality.
