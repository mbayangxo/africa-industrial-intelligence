# Mission 001 deliverable structure

This is the planned evidence package, not a promise that every question will have an answer.

```text
missions/001-senegal-rice/
├── 00-governance/          # approved brief, decisions, scope/change log, run manifests
├── 01-methods/             # definitions, taxonomies, sampling, instruments, limitations
├── 02-system-baseline/     # national/subnational flows, timeline, actors, maps
├── 03-production/          # agronomy, water, inputs, harvest/post-harvest
├── 04-trade-markets/       # trade, prices, competitors, channels, corridors, finance
├── 05-consumer-packaging/  # product performance separate from pack/brand evidence
├── 06-processing/          # process, quality, safety, standards, engineering
├── 07-machinery/           # duty specs, lifecycle, purchase/assemble/fabricate/redesign
├── 08-infrastructure/      # shared power, water, storage, logistics, labs, maintenance
├── 09-circularity/         # material ledger, relationship graph, candidate loops
├── 10-independent/         # sealed blind discovery packet and provenance manifest
├── 11-opportunities/       # candidates, rejected ideas, evidence maps
├── 12-scenarios/           # only gate-eligible models and separate wealth components
├── 13-red-team/            # disproof memos, responses, residual risks
└── 14-synthesis/           # six-question answer, decisions, gaps, next actions
```

These folders are created only when research is authorized and must not contain restricted raw artifacts.

## Required synthesis views

* Executive decision brief organized by the six controlling questions—not by available datasets.
* Subnational system map with data-coverage layer and non-comparability warnings.
* Ten-year-or-best-available trend book distinguishing baseline, shocks and gaps.
* End-to-end process/material flow and infrastructure dependency maps.
* Consumer/product/packaging comparison with behavior versus perception separated.
* Opportunity register, explicit `do not build` register, independent-discovery annex, and red-team outcomes.
* Scenario book only for eligible questions; every value links to a claim, source, assumption or scenario.
* Separate productive-wealth component table; no combined wealth-created value.
* Source, claim, discrepancy, methods, limitations, data dictionary and change-log annexes.

## Status language

Use `observed`, `reported`, `estimated`, `assumed`, `scenario`, or `hypothesis` consistently with record classification. Dashboards or narrative must not turn missing evidence into zero, national values into local values, historical values into current values, or candidates into recommendations.
