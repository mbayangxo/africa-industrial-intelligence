## Handoff protocol

Every handoff contains: scoped question; methods; search/field coverage; claim/source/relationship IDs; original units/currencies; geography/time; definitions; conflicts; confidence; missing evidence; privacy/access restrictions; and the decision the receiver can make. Receiver records acceptance, rejection, or clarification; changes do not overwrite the original.

## Independence controls

The independent-discovery agent receives only the neutral system brief, definitions, geography/time rules, evidence standard, and six controlling questions. It does not receive the candidate examples in the founder directive, opportunity drafts, founder solution hypotheses, or other discovery agents' work. Access is technically separated where possible. The agent signs a prompt/input manifest and seals its output before synthesis. If blinding is breached, label the run non-independent and rerun or exclude it from the independent quota.

The Skeptic did not author the candidate or model it reviews. The Director cannot substitute an aggregate score for the Skeptic's review, and only the founder can authorize external or consequential use during this phase.
