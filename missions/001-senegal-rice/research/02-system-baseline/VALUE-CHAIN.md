# Senegal rice value chain — evidence collection frame

**Status:** not evidenced; this is a collection frame, not a factual map.

The evidence review must test, rather than assume, the relevance and arrangement
of the following stages in each production system and geography:

`seed/input → production → harvest → drying → storage → transport → milling → grading/sorting → packaging → wholesale → retail → household/food service`

For each evidenced stage, the eventual map must record:

* actor type and geography;
* ownership or contracting arrangement only where reported;
* material quantity, quality state and timing;
* price, fee or margin with currency, date and transaction definition;
* infrastructure, finance and regulatory dependencies;
* loss or quality-change evidence;
* handoff to the next stage; and
* source IDs, claim IDs and unresolved contradictions.

file because source content was inaccessible during this run.
